Privacy Policy

Last updated: August 2, 2026

GitHub Thread Expander is a browser extension that opens hidden comments, replies, and timeline threads on supported GitHub pages.

Information processed by the extension

To work on the page you choose, the extension processes the following information locally on your device:

  • The URL of the active GitHub page
  • Visible page elements and button labels needed to find hidden threads
  • Whether a GitHub comment or review editor contains unsaved text
  • Temporary progress and status information

The extension checks only whether a draft contains text. It does not save or retain the contents of comments or review drafts.

How this information is used

The extension uses this information only to:

  • Check whether the current GitHub page is supported
  • Find and activate visible “Load more” controls
  • Avoid running while an unsaved comment or review is open
  • Show expansion progress in the extension popup
  • Remember the current status during the browser session

Temporary storage

The active page URL and expansion status may be stored temporarily using Chrome’s session storage. This information remains on your device and is kept only for the current browser session.

Data transmission and sharing

GitHub Thread Expander does not send this information to the developer or to any server operated by the developer.

The extension does not sell, share, or transfer user data to third parties.

Analytics and advertising

The extension does not use analytics, tracking, advertising, or profiling services.

Limited Use

GitHub Thread Expander uses page information only to provide its thread-expansion features.

Its use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to this policy

This policy may be updated if the extension’s features or data practices change. Any updates will be published on this page with a revised date.
